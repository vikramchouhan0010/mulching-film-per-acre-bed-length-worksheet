# Mulching Film per Acre: Bed Length Worksheet

Mulching film is bought by the running metre, the roll or the kilogram. The quantity comes from one number: metres of bed an acre holds.

## Method

1. Bed length = 4,047 m2 divided by the bed spacing (centre to centre).
2. Add about 3% for the start, the finish and joins.
3. Film width = bed top plus the buried edge on both sides. A 0.9 m bed top with 0.1 m buried each side needs 1.1 m, so 1.20 m film fits and 1 m does not.
4. Weight, as a planning estimate = area x thickness x 0.92 g/cm3.
